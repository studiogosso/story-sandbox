### なぜ16歳か
- 機織りを5〜6年見てきた手がある。作業は任せられる段階
- まだ大人ではない。外の世界(商人の家、市街、男、革命)を怖がるが見たい
- 妹弟にとっては「お姉ちゃん」、両親にとっては「まだ子ども」、徒弟たちにとっては「年上だが年下」 — 家の中で立ち位置が揺れる年齢
- 1831年11月蜂起のとき身体が動ける。でも判断は狂える

## 名前の候補

リヨン由来/1831年当時現役の名前から。最終決定は保留、耳の手触りで選ぶ。

| 候補 | 手触り | Why / How |
|---|---|---|
| **Blandine** | 芯、古い、まっすぐ | リヨンの守護聖人 Sainte Blandine。直球すぎて重いが、蜂起の娘にはむしろ合う |
| **Victorine** | 硬さと湿り | 「勝利」の女性形。名前が勝つ時代に、本人は勝たない。アイロニーが効く |
| **Joséphine** | 柔らかい、家庭的 | 当時もっとも普通の名前の一つ。凡庸さが物語の強さになる |
| **Célestine** | 上 / 空 / 工房の天窓 | sous-pente の娘が「空」の名を持つ。垂直空間と呼応 |
| **Pauline** | 小さく、固い | 少しだけ男性形(Paul)から溶けた名。独立職人の娘に合う |

→ **第一推し: Célestine**(屋根裏=天窓の娘、垂直構造と名前が呼応)
→ 第二: **Blandine**(リヨンの土)

## 家族構成(ドラフト)

### 父 — canut、42歳
- 本名: Jean-Baptiste(仮) / 通称: **Le Père** または **Jean**
- 10歳から織機の前。親方になって15年。
- 織機は4台所有(独立職人の中堅)。fabricants に糸を預かり、仕上げた反物を収めて賃を受け取る
- 手の皮が厚く、爪は茜で染まる
- bistanclaque のテンポが体内時計。自分の息でペダルを踏む
- **誇り**: 自分の織る柄(紋織)が他の家より評価が高い
- **怯え**: 蒸気力織機の話を聞く度に黙る。口にしない

### 母 — 織り子、38歳
- 本名: Marie(仮)
- 父と同じ部屋で働く。夫の下拵えではなく対等な織り手
- 一日の中で**歌いながら筬を打つ**ことがある。娘の子守唄だった歌
- 娘の体調を匂いで測る(「今日は熱い」「今日は青い」)
- 蜂起の朝、夫より先に黒旗の存在を知る(井戸端で)

### 娘 — **Célestine**、16歳
- 5年前から織機の横で糸を揃え、今は一番単純な反物なら一人で織れる
- **夢**: 自分の柄を作ること。親方の誇りを引き継げるか不安
- **癖**: 絹の手触りで心の動きを隠す。怖いとき縦糸を撫でる
- **恋**: 隣家の靴職人の息子(15歳)と目を合わせる。言葉は交わさない
- **秘密**: 叔父(父の弟)の工場に行ったことがある。父には黙っている

### 弟 — 8歳
- 仮名: Louis
- まだ学校に通っている年齢(教育法は1833年ギゾー法、翌々年)
- 織機の下で紙と鉛筆。絵を描く
- 徒弟たちの笑い話を盗み聞きする係

### 徒弟2人
- **17歳、Étienne** — 親方の兄の息子。甥。寡黙、器用、Célestine に視線をやらない(意識している)
- **14歳、Antoine** — 他の町から来た。地方訛り、ホームシック、bistanclaque の音で眠れる

### 叔父 — 父の弟、37歳
- 仮名: **Paul**
- 5年前に蒸気力織機の工場に移った。家では**名前を出さない**存在
- 賃金は canut 時代より安定している。でも子どもを早く産めなかった(工場の時間のせい)
- 兄を訪ねてくる時は、**靴音が違う**(工場の床は硬い)
- 蜂起の夜、兄と弟は別の位置に立つ

## 家族内の閾値(機械 vs 手仕事)

一本の家族の中に、3つの未来が同居する:

| 人 | 未来への向き |
|---|---|
| 父 | 古い時代の側。誇りで死ねる |
| 母 | 揺れる。娘の体で判断する |
| Célestine | 見ていない。見たい |
| 弟 Louis | 読み書きができる世代。次の50年は彼の世代 |
| 徒弟 Étienne | 親方になる前に親方の仕事が消える世代 |
| 叔父 Paul | 既に向こう側。家にもう帰らない |

**映画の縦軸**: この閾値が一つの部屋の中で起きている。

## 家の物理設定(65㎡ / 天井4m)

- 床は木。窓は床から天井まで(採光のため)
- 1階: 親方の織機2台、母の織機1台、台所(竈、洗い場、食卓)、玄関
- 2階: 徒弟の織機2台、作業用テーブル、糸の貯蔵
- 屋根裏 sous-pente: Célestine と Louis の寝床、父母の寝床(カーテンで区切る)、Étienne と Antoine の寝床

家の中での音響設計:
- 朝、まず父の織機が鳴る(起床合図)
- 母の織機が少し遅れて入る
- 徒弟たちが上から降りてきて、2階の織機が鳴る
- Célestine は糸を揃えながら全体のリズムを聴く
- 全員揃うと、bistanclaque-pan が**四つの声の合唱**になる
- 昼、誰かが食卓に降りると一台止まる。止まった分だけ他の音が立つ
- 夜、最後に父の織機が止まる。それまで誰も先に止められない

## 物の地図(アイテム)

Célestine の物理空間に固定される物:

- **縦糸の束**(彼女の係)— 色の順番を間違えたら一日無駄
- **鋏(はさみ)**— 祖母から受け継いだ鋼。磨くのが彼女の役目
- **小さな手鏡**— 母から貰った。工場の窓ガラスより小さい
- **茜で染まった布切れ**— 失敗作、父の許可で取っておいた
- **靴職人の息子から貰った木の指輪**— 誰にも見せていない
