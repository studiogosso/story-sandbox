# 構造エンジン — 型1 + A

## 採用型: The Big Short モデル(型1)

**原理**: 視聴者に前提知識を与えながら、その知識で世界を爆破する。
**痛快の源泉**: 「理解できた!」の瞬間。

### 先行作品に見る型1の動き

- The Big Short: 金融の仕組みを素人に解説 → それが崩壊する
- Mr. Robot: ハッキングの世界を見せる → 資本主義が揺らぐ
- シン・ゴジラ: 官僚機構の動きを開示 → 怪獣対応に落とす
- 沈黙の艦隊: 軍事/国際法を開示 → 地政学に繋がる
- Spotlight: 調査報道の手順を見せる → 組織的隠蔽が暴かれる

### 型1が要求する設計

1. **前提知識を視聴者に授ける**場面が定期的に入る(退屈させずに)
2. **知識で世界を動かす/爆破する**瞬間がクライマックスに配置される
3. **主人公が「質問する側」**でいられる構造(完全に詳しいと学習場面が作れない)

## 主人公ポジション: A(半分プロ、半分素人)

**定義**: 専門家だが全体像は追えてない。自分の分野は深く知るが、その分野が社会全体にどう繋がっているかは分からない。

### このポジションの強み

- 視聴者と一緒に学ぶ窓として機能する
- プロの目で微細な違和感を拾える(素人視点では気づけない)
- 「この分野では答えられるが、他は分からない」という謙虚さが共感を呼ぶ
- 成長曲線が描きやすい(専門 → 横断 → 世界観)

### 先行例

- Mark Baum(Big Short) — ヘッジファンド運用のプロ、でも住宅市場の腐敗はこれから知る
- Elliot Alderson(Mr. Robot) — ハッカーのプロ、でも社会運動家ではない
- 矢口蘭堂(シン・ゴジラ) — 官僚のプロ、でも怪獣は初めて
- 海江田艦長(沈黙の艦隊) — 軍事のプロ、でも国際政治の駒になる

## 視聴者体験の設計

```
第1段階: 主人公の専門世界に浸る(15分) — ここでプロ性を見せる
第2段階: 専門の中で違和感を発見(15分) — 問いが立つ
第3段階: 違和感を追うと世界が開く(30分) — 学習フェーズ
第4段階: 学んだ知識で動く(30分) — 痛快フェーズ
第5段階: 世界は完全には理解できないと知る(15分) — 成熟
```

## 型1の罠

- **情報過多で眠くなる**: 解説が多すぎると失速。人間ドラマで薄めること
- **教条的になる**: 「これが真実だ!」と言い切ると白ける。謎は残す
- **主人公が全知になる**: どこかで必ず「わからない」場面を残す
- **痛快さを忘れる**: 批評眼が勝ちすぎると陰鬱になる
