# Story Incubator — 5企画並列孵化器

**作成日**: 2026-04-20
**発端**: story-kickoffスキルでの対話から、5つの哲学テーマ × 型1+A型主人公 で5企画を並列に育てることにした

## 共通設定(全5企画が継承)

- **ムード**: 世界は暗いけど話は明るい / バックボーン複雑だが表層は明快で痛快
- **型**: 型1 = The Big Shortエンジン(視聴者に学ばせる快感。主人公がちょっとずつ世界を解読し、「そういうことか!」の爽快感を定期供給)
- **主人公ポジション**: A = 半分プロ、半分素人(専門家だが全体像は追えてない)
- **最終形**: 世界向けCGアニメーション(今はこれ気にせず考える)
- **「つかむの難しい」の主感触**: どの立場が正しいか分からない × 情報を追うのが難しい × 前提知識がない

## 種プール(Seed Pool)

`_seeds/` が**共通の素材庫**。新企画を作るときはここから引き出す。使わなかった端材はここに戻る。

- `_seeds/philosophies.md` — 哲学/思想の種(34個+)
- `_seeds/moods.md` — ムード形容詞の種
- `_seeds/protagonists.md` — 主人公プロ分野50個
- `_seeds/references_works.md` — 参考作品(CG/実写/小説/ドキュ)
- `_seeds/core_questions.md` — 「もし〇〇だったら」の種42個+
- `_seeds/offcuts/` — 各企画から戻ってきた端材(再利用可)

詳細は `_seeds/README.md` 参照。

## セッション切り替えルール

各企画は**別セッションで独立して進められる**。

新セッションで:
- 「**01のつづき**」「**03を進めよう**」等と言えば、該当企画を再開
- Claude は `MEMORY.md` → `project_story_XX_*.md` → 該当フォルダの `progress.md` の順に読む
- `progress.md` に**現在地**と**次にやること**と**再開コマンド**が書かれている

## 増殖のルール

- 各企画が深まると**孫案**(例: 01 × 医療、02 × 翻訳)が生える → `0X/spinoffs/`
- 2つの子を掛け合わせた**クロス受粉**(例: 03+05=偽物の図書館司書)も可 → 新フォルダ `06_cross_*/` として独立させる
- 親の共通設定はここ(`00_parent/`)で一元管理。子には書かない(DRY)
