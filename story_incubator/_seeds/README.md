# Seed Pool — 種プール

物語の**種**を貯める場所。企画を作るときの素材庫。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `philosophies.md` | 哲学/思想の種(ポストトゥルース、公共圏、etc) |
| `references_works.md` | 参考作品の種(映画/アニメ/小説/ドキュ) |
| `moods.md` | ムード形容詞の種(暗い×明るい等のコントラスト) |
| `protagonists.md` | 主人公プロ分野の種(金融/ハッカー/司書等) |
| `core_questions.md` | 「もし〇〇だったら」の種 |
| `offcuts/` | 企画から戻ってきた端材(再利用可能) |

## 動作ルール

### 企画を作るとき(Claudeの動作)

ユーザーが「物語作りたい」「企画考えたい」と言ったら、Claudeは:

1. **この `_seeds/` を開いて、関連する種を全ファイルから抽出**
2. **表形式でまず提示**(哲学/参考作品/主人公候補/ムードをカテゴリ別に)
3. ユーザーに**「ここから選ぶ? 混ぜる? 新しく作る?」**と聞く
4. 選ばれたものを元に STEP 1 以降に進む
5. **選ばれなかった種は `_seeds/` に残す**(消さない)

### 企画を進めるとき(端材の扱い)

企画進行中、検討したが採用しなかった要素は `offcuts/{企画番号}_{名前}_offcuts.md` に戻す。

例: 01_post_truth で「ハッキング主人公」が候補に出たが採用しなかった
→ `offcuts/01_post_truth_offcuts.md` に「ハッキング主人公案(不採用: 〇〇の理由で 02 向き)」と記録

**理由も必ず残す**。別企画で使う時の判断材料になる。

### 種を追加するとき

新しい哲学・作品・ムード等を知ったら、該当ファイルに追記。
「これは使わないかもしれないが面白い」と思ったら必ず種として残す。
