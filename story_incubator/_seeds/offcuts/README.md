# Offcuts — 端材置き場

企画進行中に**検討したが採用しなかった**要素の保管庫。

## ルール

1. ファイル名: `{企画番号}_{企画名}_offcuts.md`
   - 例: `01_post_truth_offcuts.md`
2. 各端材に**不採用理由**を必ず記録
3. 「別企画で使えそう」な示唆があれば記録
4. 時期が来たら(例: 半年ごと)見直して `_seeds/` の本体に昇格させる

## 端材の種類

- 検討した主人公候補(採用されなかった)
- 検討した核心の問い
- 検討した世界設定
- 検討したキャラ
- 検討した参考作品(トーンが合わなかった)
- 検討したビジュアル方向性

## 書式

```markdown
# 01 Post-Truth — 端材

## 日付: 2026-04-20

### 主人公候補: 軍事/諜報(J26)
- 不採用理由: 偽情報工作側の視点は内省的すぎ、痛快さが出にくい
- 別企画で使える?: 04 Foucault's Pendulum に合いそう(陰謀を作った側が飲まれる)
- メモ: スパイもの + 寝返りの物語として別企画化の可能性

### 核心の問い: Q35「もし秘密が禁じられたら」
- 不採用理由: 01のテーマ(真実の無力化)とズレる
- 別企画で使える?: 02 Public Sphere 向き
```

## 端材の活用タイミング

- **別企画の開始時**: `_seeds/` と合わせて offcuts も参照
- **アイデア枯渇時**: 過去の端材から意外な組み合わせを探す
- **クロス受粉**: 複数企画の端材を掛け合わせて新企画(例: 03+05の端材)

## 捨てない理由

**端材は無料の素材**。時間を経て見返すと光ることがある。
当時の判断が間違っていることもある。
捨てるコストより保管コストの方が安い。
