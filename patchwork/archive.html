Category A

裁縫・糸・布
少女の職能「普通の裁縫」と共鳴する存在
IMAGE
スラブ神話
キキーモラ
Kikimora
家に棲む女性精霊。機織り機を愛し、夜中に機を織る音を立てる。働き者の主婦には協力し、怠け者を食べてしまう。ドモヴォイの妻とされることも。
機織り家の精霊夜の仕事
仕立て屋夫婦の「妻側」の血統。布・糸と人間の家の間に棲む存在として参照できる。夜中の作業音が少女の仕事場の空気になる。
針女（はりおんな）
画像：伝承記録なし
日本 / 愛媛県伊和島
針女
Hari-onna
長く乱れた髪の先端が針状に曲がった女妖怪。夜に現れて笑いかけ、笑い返した者を髪の針で捕まえる。身体そのものが縫製道具に変化した存在。
針髪捕獲
少女の針と糸の鏡像。「縫う行為」が武器にも儀式にもなることを示すイメージ。

Category B

家・建物に宿る
仕立て屋夫婦・街の住人の血統。場所に縛られた神
IMAGE
スラブ民間信仰
ドモヴォイ
Domovoi
家の暖炉や隅に棲む精霊。供物があれば家を守り、ないがしろにすると害をなす。家主の死とともに家を離れ、新居に移ることも。家そのものと一体化した存在。
家の守護暖炉供物
仕立て屋夫婦の「夫側」の血統。店（家）に縛られ、漂流してきた少女を「拾う」論理がある。
IMAGE
日本 / 室町時代
付喪神の行列
Tsukumogami
99年経った道具が命を持ち、百鬼夜行に加わる。からかさ小僧（一本足・一つ目・長い舌）が代表。道具が変化した存在であり、人間の生活の残骸が歩き始める。
道具→生命百鬼夜行一本足
街の住人の設計原理。「変な身体」の多くは、元は別のものだったという出自を持てる。服を縫われた身体が変化する、という逆転も可能。
バンニク
画像：伝承記録なし
スラブ神話
バンニク
Bannik
浴槽に住む精霊。湯を残さず出ると水中に引きずり込む。浴場そのものが人格を持った場所として機能する。洗うこと・湯気・水辺の管理者。
浴槽水辺引きずり込む
「水と家の境界」に棲む存在。少女の仕立て屋（家）と川（水）の間に挟まる層の住人として。

Category C

水・川・溺死
水がトーテム。死んだ兄（ドラウグル系）、漂流する少女の血統
IMAGE
スラブ民間信仰
ルサールカ
Rusalka
水の事故で死んだ女性が変化した精霊。緑色の髪、透き通った肌。川で死者の衣服を洗う姿も目撃される。死と水が融合した存在で、男性を水中に誘い込む。
溺死→変化川死者の衣服を洗う
「川で死者の衣服を洗う」イメージが少女の裁縫と直結する。死→水→布→縫う、という連鎖のモデル。
IMAGE
北欧伝承
ドラウグル
Draugr
溺死者の亡霊。死後も腐敗した身体で動き続ける。巨大な力を持ち、船を沈め、叫び声で死を予兆する。人間の時より大きく、より制御不可能になった存在。
溺死死後も動く巨大化船を沈める
最初の客（死んだ兄）の最も直接的な血統。溺死→大きい→制御できない力、という三要素が完全に一致する。
IMAGE
アイルランド / ケルト
バンシー
Banshee
死が近い人の家で泣く女妖精。川で死者の衣服を洗いながら泣く姿が目撃される。その泣き声が死の予兆。声が水を伝って世界を変える存在。
泣き声川で洗濯死の予兆
赤ん坊「泣くと水が応える」との共鳴。泣き声が川に届くというモチーフの祖型。
カイポクングル
アイヌ神話 / 画像資料なし
アイヌ神話
カイポクングル
Kaipok-un-guru
「波下に棲む者」の意。海辺の波下に棲み、船を沈めて人間を溺死させる悪神。水面の下にいて上から見えない、というのが恐怖の構造。
波の下船を沈める不可視
横転した戦艦と川の底、という世界の「下」にある存在として参照できる。

Category D

身体変形・奇形
街の住人たちの血統。人間の形を逸脱した存在
IMAGE
中国 / 山海経
形天
Xingtian
黄帝に首を斬られた無頭の神。胸に目、臍に口を持ち、楯と斧を手に永遠に戦い続ける。首がなくても生きている、器官の位置が完全に倒錯した存在。
無頭胸に目倒錯した器官山海経
身体変形の住人設計の典型例。「どこに目があってもいい」「頭がなくていい」というラディカルな身体観。少女にとって採寸から始まる服作りの難度を示す。
IMAGE
中国 / 山海経
夔
Kui
一本足の神牛。雷と音の神とも言われ、太鼓の材料になったとされる。欠損した身体こそが神聖さの証。一本足のバランスを保って立ち続ける。
一本足雷神欠損の神聖さ
街の住人に「足が一本」「腕が一本」の存在が登場するとき、そこに夔の血統がある。欠損は呪いではなく由緒として機能できる。
IMAGE
バビロニア神話
ラマシュトゥ
Lamashtu
ライオンの頭、ロバの牙、猛禽の爪を持つ悪神。ロバの上に立ち、野豚とジャッカルに乳を与える。乳児を連れ去る夜の存在。複数の動物器官が継ぎはぎされた身体。
複合身体乳児を狙うロバの上
「赤ん坊を届ける旅」の緊張の祖型。ラマシュトゥ的な存在が赤ん坊を求めているかもしれない。継ぎはぎ身体は少女の裁縫の鏡像でもある。
IMAGE
北欧民話
フルドラ
Huldra
美しい女性の姿をした精霊。しかしスカートの下に牛の尻尾と空洞の背中を隠している。見た目と真の身体が異なる。森で男性を誘惑し、破滅させる。
空洞の背中尻尾を隠す外見と身体の乖離
「服で隠されていた身体が採寸で暴かれる」という仕立て屋の行為の核心。服を縫う前に、身体の秘密が少女だけに見える、という場面の設計に使える。
IMAGE
メソポタミア神話
パズズ
Pazuzu
ラマシュトゥを護符の表面から監視する有翼の悪霊。悪を封じるもう一つの悪。身体は複数動物の混合体で、正面から見ると四肢の方向がバラバラに広がる。
有翼複合身体対立する悪
神々の一家の誰かに使える身体造形の参照。「悪を制する悪」としての役割は、神々の家族の中の誰か一人に与えられる可能性がある。

Category E

多神共存の体系
荒唐無稽な世界の設計原理。一体系に縛られず神と化け物が雑居する
IMAGE
日本 / 国際日文研蔵
百鬼夜行絵巻
Hyakki Yagyo
夜、百の鬼や妖怪が行列をなして練り歩く光景。各個体はそれぞれの出自と形状を持ちながら、同じ夜の空間に雑居する。体系なき多様性の祝祭。
多神雑居行列夜の世界
patchworkの世界の設計原理そのもの。街の住人は「どこかの神話体系に属する」のではなく、百鬼夜行的に各自の出自を持ちながら雑居している。
IMAGE
アイルランド / ケルト
プーカ
Púca
山・丘に棲む変身能力を持つ妖精。「救われるほど良くもなく、救われぬほど悪くもない」道徳的に曖昧な存在。秋の収穫と結びつき、11月1日が「プーカの日」。
変身道徳的曖昧さ山に棲む
神々の一家の設計原理として。完全な悪でも善でもない、ただ強い、という存在の典型。山に住む、というのも符合。
IMAGE
インド / 東南アジア
ナーガ
Nāga
蛇の体と人間の上半身を持つ水の神。夫婦で存在することが多く、寺院の守護者として広く描かれる。仏教とヒンドゥーが混在した存在で、地域によって性格が異なる。
夫婦で存在蛇×人間水と寺院
仕立て屋夫婦の別バリエーション。夫婦で一対になる神という構造の参照。川と建物（仕立て屋）の両方と関係する存在として。

Category F

赤ん坊・子の形をした神
「泣くと水が応える」赤ん坊の血統
雪女の赤ん坊
鳥山石燕「今昔百鬼拾遺」
デジタル画像は著作権確認要
日本民間伝承
雪女の抱く赤ん坊
Yuki-onna / baby
豪雪の夜に現れる雪女は赤ん坊を抱いている。「この子を受け取って」と言い、受け取った者は凍死する。赤ん坊は武器、餌、あるいは呪いそのもの。
赤ん坊を抱く受け取ると死冬の怪
「赤ん坊を誰かに渡す」という行為の危険性と神聖性。少女が受け取った赤ん坊は、雪女の赤ん坊のような呪いの質感を少し持っていてもいい。
水虎（うがら）
九州地方の伝承 / 図像資料なし
日本 / 九州
水虎
Suiko / Ugara
子どもの姿をした川の怪。川遊びをしている子どもに見えるが、水中に引きずり込む。子どもの形をした危険な水の精。無邪気さと致命性が同居する。
子どもの形川引きずり込む
赤ん坊の「泣くと水が動く」力の祖型。子どもの形をした水の存在、という設計の参照。
IMAGE
バビロニア神話
ラマシュトゥ除け護符
Anti-Lamashtu plaque
乳児を守るために作られた護符板。ラマシュトゥが乳児を狙うため、あらゆる魔除けが生まれた。乳児＝最も守られるべき存在、かつ最も危険な存在。
乳児を守る護符古代の不安
「赤ん坊を山へ届けなければならない」という物語の緊張の古代的祖型。護符が必要なほど危険にさらされた赤ん坊、という原型。
