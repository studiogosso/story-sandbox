Design DNA

SYNTHESIS — FROM ARCHIVE TO CHARACTER
神話アーカイブで集めた素材を、patchwork の登場人物・勢力に割り当てる。
一神教ではなく多神共存の世界。複数の血統を縫い合わせて1キャラを作る。

世界の縫い目

この街は 百鬼夜行 (Hyakki Yagyo) 構造で動く。中心となる神話体系は持たない。スラブの家精、北欧の不死、メソポタミアの守護獣、中国の異形戦神、日本の付喪神 — それぞれ無関係に、同時に存在している。

住人ひとりにつき身体変形がひとつ。腕3本、下半身なし、毛だらけ、羽 — 由来は語られない。少女だけが外来者として既成概念に縛られず、変な身体用の服を縫える。

神々一家は「最終関門」だが「絶対的な悪」ではない。多くの家族のうちの一つ。たまたま戦艦に住み着いていて、たまたま川の出口を塞いでいる。

Protagonist

少女

— the human anchor
外来者。観測者。普通の裁縫しかできない。兄を水で失った側。
faint root I

brave little tailor 系

EU folktale

「弱い／力ない／針一本」だけで世界を渡る職能譚。魔法ではなく、手仕事の技だけが武器。

faint root II

水で兄妹を分けられた者

universal motif

北欧サガから日本の昔話まで、水（川・海）で兄弟が引き裂かれる物語は普遍。少女はその「残された側」。

意図的に血統を持たせない

少女は神話の血を引かない。観客の代理人として、神々と化け物だらけの世界に投げ込まれる純粋な人間。能力は針と糸だけ。

視覚キー

  • 服そのものは継ぎ接ぎだが、左袖だけ綺麗 — 兄が縫ってくれた最後の一部
  • 常に首から針入れを下げている（指輪より動きやすい）
  • 髪は短い（兄の死後、自分で切った）

死んだ兄

大柄、狂暴化できる、水で死んだ。少女には正体を明かさない。
primary root

Draugr / ドラウグル

Old Norse

水辺・墓から這い出る不死の戦士。生前より大きく、青黒く膨れ、家族や家を守ろうとする執着で動く。→ archive

secondary root

Berserker / ベルセルク

Old Norse

意識を失うほどの怒りで戦う。普段は穏やかだが、家族の危機で別人格に切り替わる。狂暴化＝守るためのモード。

visual root

パッチワーク人間 [38]

sketch lineage

全身が継ぎ接ぎ。少女が縫ってあげた服が、徐々に兄自身の体と区別がつかなくなる。異界に滞在するための仮の体。

結晶

水で死んだ青年が、異界の素材で「仮の身体」を組み立てて戻ってきた存在。少女が縫う服そのものが、彼を異界に繋ぎ留める縫合糸になる。

狂暴化のトリガー

  • 少女が物理的な危機に晒されたとき
  • 水（川・雨）に触れたとき — 死の記憶が逆流する
  • 狂暴化中は声が出ない（喉から水音が漏れる）

視覚キー

  • 左胸に古い針穴が一列 — 死因の痕
  • 狂暴化すると縫い目が裂け、中から異界の海水が滴る
  • 瞳が常に少しだけ濡れている

水虎 / Suiko

Banshee / バンシー

tertiary root

雪女の子 / 雪ん子

日本

異界の女性が産む子供のモチーフ。「人ではない母から生まれ、人の世界に置き去りにされる」型。

結晶

水を司る幼神の片割れ。本来は山で生まれるはずが、何らかの理由で街に流れてきた。山に届けるとは 「本来の場所に戻す」 こと — 100年に1度の逆流の起点でもある。

泣くと水が応える ルール

  • 小さな泣き → 露／霧／井戸の水位
  • 普通の泣き → 雨／水溜まり／川の流れの方向
  • 本気の泣き → 川そのものが動く（逆流の引き金）
  • 赤ん坊は泣くたびに少し小さくなる（旅の終わりが近づく）

視覚キー

  • 掌が魚のヒレのように水掻きになっている
  • 涙が地面に落ちる前に小さな波紋を作る
  • 瞳に常に水面の反射が映る

flavor root

付喪神 / Tsukumogami

日本

店の道具一式（ハサミ、ミシン、糸巻、メジャー）が 夜になると勝手に動く。夫婦と道具の境界が曖昧。

結晶

人ではない夫婦。少女を「家族にする」のではなく「客として置く」。労働で生活させ、最低限を教え、深入りしない。情はあるが、決してハグしない。

関係性のルール

  • 少女のことを名前ではなく「お前」「うち子」と呼ぶ
  • 食事は別の机
  • 少女が泣いても黙って針を貸す
  • 別れの時、夫婦は見送らない（窓の影だけ動く）

視覚キー

  • 夫：背中に縫い目、毛深い、低い椅子で常にキセル
  • 妻：6本指（多指症的）、糸巻を首飾りにしている
  • 店の天井：吊るされた仕掛けがゆっくり回る（風がないのに）

flavor root

Domovoi の眷属

Slavic echo

熊は東欧で家の守護獣。仕立て屋夫婦の家系が、出張用に作って忘れていた人形 — という背景もありうる。

視覚キー

  • 小熊：左耳が欠けていて、少女が後で布で繕う
  • お互いに紐で繋がっていて、戦闘時だけ自分でほどく
Final Threshold

神々一家

— Pazuzu's family × Xingtian × Hyakki Yagyo logic
横転した戦艦に住み着く。父神・母神・子の神々。倒す対象ではなく通過／交渉する相手。
primary root

Pazuzu の家族構成

Mesopotamian

パズズには配偶者ラマシュトゥと子供がいる。悪魔ではなく「特定の領域の支配者」。家族単位で領域を持つ古代神の型。→ archive

secondary root

刑天 / Xingtian

中国

頭を切られても胸の乳首を目、臍を口にして戦い続ける。敗れた後も諦めない神。神々一家が「かつて敗れた者」である理由付け。→ archive

structural root

百鬼夜行 / Hyakki Yagyo

日本

多くの異形が同時に存在し、整理されない。神々一家は 「多くの家族のうちの一つ」。彼らの戦争も内輪揉め。

結晶

かつて他の神々と戦って敗れた一家。横転した戦艦は彼らの負け戦の証拠であり、同時に住居でもある。誰と戦ったかは具体化しない（「もう忘れた」と父神が言う = 案D相当）。多神共存世界の整合性が取れる。

家族構成（試案）

  • 父神：刑天型 — 巨体、頭を失っているか覆われている。台詞少ない
  • 母神：ラマシュトゥ型 — 子供を護るため攻撃的、しかし赤ん坊には情を見せる
  • 子の神々（複数）：道化的、好奇心で少女に近づく — 一番危険

関係性のルール

  • 戦闘では勝てない（少女は針一本）→ 交渉／供物／祈りのみ
  • 赤ん坊を見せると母神が動揺する（同類だと察する）
  • 横転戦艦は逆流時、彼ら自身が立てない＝水が彼らに味方しない
  • 少女が差し出す対価は 「兄に縫った服の左袖」（最も大事な布）

視覚キー

  • 戦艦：錆びた鋼、貝殻、藤壺、内部は真菌で発光
  • 父神：装甲が付喪神化していて、戦艦と区別がつかない
  • 母神：腕が異常に長く、子供を抱える時だけ柔らかく見える
