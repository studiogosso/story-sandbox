Emotional Core
借り — 生かされた側の物語
この作品の全てを貫くのは 水。
少女は水で兄を失い、水に流されて異界に漂着し、水を逆流して帰る。
水が神でも敵でもなく、物語そのものの呼吸である。

物語の骨格

世界

異界の街。住人は身体が変形している（腕3本、下半身なし、羽、毛、液体が染みる、ねじれ）。普通の仕立て屋では服が作れない。外来者の少女だけが、既成概念に縛られず変な身体用の服を縫える。だから彼女は生きていける。

魔法じゃなく職能

少女の能力は普通の裁縫。魔法ではなく現実の技術。この街が歪んでいるから、普通の技術が珍しい力になる。針・糸・型紙・採寸。それだけ。

ストーリーエンジン

ある日、店に駆け込んだ誰かが赤ん坊を置いていく。「この子を山へ届けて」。化け物夫婦は関わりたがらない。少女が引き受ける。最初の客（兄）が付いてくる。

旅の途中、100年に一度の川の逆流が近づいていることを知る。その日に間に合わなければ、少女は元の世界へ帰れない。

感情核

少女は兄に水の中でかばわれて死なせた側。生かされた命をどう使うかの試行。

赤ん坊を山へ届ける＝受け取った命を次の誰かに託す行為。

キャラクター・パーティー

最小構成5人。旅の中で段階的に加入する。

少女 — 主人公
WEAK / IGNORED / STITCHER
弱い。腕っ節もない。口も立たない。街の誰にも見えない、無視される。
だが裁縫ができる。生前、兄に川でかばわれて生き残った過去を抱える。
兄を失って、泣けなかった子。[20]
最初の客 — 死んだ兄
FIRST CUSTOMER / LARGE / BERSERK
ガタイがとても大きい。狂暴化できる。かつて少女を水でかばって死んだ兄が、異界で最初の客として現れる。
少女が彼に服を縫ってあげる＝生前できなかった喪の儀式。
少女は最後まで彼が兄だと気づかない。観客だけが途中で気づく。 [5] [18]
赤ん坊 — 化け物＋特別な力
BABY / WATER-SUMMONER
化け物の赤ん坊。泣くと水が応える（動く・満ちる・引く）。
山へ届けなければならない、ここに居てはいけない存在。
100年の逆流の奇跡のトリガーになる可能性。
仕立て屋の夫婦 — 拾い主
MASTER COUPLE / NOT-HUMAN
化け物の老いた夫婦。人ではない。かつて人間と関わった経験があり、漂着した少女を拾う。
少女のガイド・通訳として機能するが、本当の家族にはなれない距離感を最後まで保つ。
熊のぬいぐるみ × 2 — 旅の途中で加入
BEARS / TONE BUFFER
熊の広間での事件を経て一行に加わる。トーンの緩衝材、観客の入口、少女の幼さの名残り。
2匹で掛け合える＝画面が持つ。[17]

最終関門 — 戦艦に住み着いた神々

悪役ではなく、越えがたい他者

川の終わり、横転した巨大な戦艦の残骸に、神々の家族が住み着いている。父神・母神・子の神々。かつて世界を荒らした。今は敗れて沈黙している。

少女たちは彼らを倒すのではなく、祈る／捧げる／通過する。90分で戦闘を入れずに緊張を出す装置。

帰還の日、少女たちはこの横転した戦艦に乗って、逆流する川を上る。神々は川を止められない側。水は神々に味方しない。

◇ 未決：神々がかつて誰と戦ったか（推し＝水神／水そのもの）
