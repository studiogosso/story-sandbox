ANIME PROJECT

EMBERFALL

隕の燠火
A brighter successor to Harry Potter — mystery, irony, and a slow-burning world.

326年前、空から落ちてきた一つの石が世界の血を変えた。
隕石に触れた者の子孫だけが「魔法」を扱える時代になって、もう七世代。
衰退した銘家の末娘 Ambre は、家の期待を背負って学院都市 RACINE に入る。
彼女に発現するのは 「復元の魔法」 — と、街も家もそう信じる。
観客だけが、それが本当は別のものだと知っている。

01 · STORY CORE

物語のコア

主人公・二重構造・物語骨格の3点セット。この背骨は S1 から S5+ まで一貫。

主人公: Ambre(アンブル)、12歳、女の子。古い銘家 EMBERLYN(残り火) の末っ子で、兄1・姉1の下の三兄妹の末子。性格は諦観まじりの朗らか。家全体が七代続く沈滞を抱え、父はその復活に熱を入れ、母は距離を取っている。

表向きの発現: 学院入学の翌週、寮の食堂で割れた古い陶器を、ほとんど無意識に元へ戻す。学院は驚き、家系を確認し、診断結果を 「復元の魔法」 と記録する。EMBERLYN 家にふさわしい古典系の力 — と、家も学院も政治家も信じる。

実体: 彼女の力は復元ではない。四代前の曽祖母が山地の TAKANI の血を一度だけ家に入れた。そのことは家の記録から消されている。Ambre の体には 八分の一の TAKANI 血統 が残っていて、彼女が「復元している」と思っているものは、実は壊れたモノの中に残る声を聴き、過去の残響と話している — TAKANI に伝わる「残響読み」の、忘れられた一形。

本作の背骨: 主人公は最後まで自分の正体を知らない。 家族も、学院も、友人たちも知らない。観客だけが真実を知るドラマティック・アイロニー。血の真相(残響読み・1/8 TAKANI・曽祖母の不義)は S4 終盤〜S5 まで温存。それまで観客にだけ滲ませ続ける。

物語骨格 ①
ミステリー・アイロニー
観客だけが真実を知る。主人公の毎話の行動原理を貫く軸。
物語骨格 ②
政治成長譚
EMBERLYN 復活の期待 → 政治の渦。家と世界の舞台装置。
物語骨格 ③
世界の謎
シーズン跨ぎの大筋。隕石再活性化 = 世界規模の変動。
物語骨格 ④
群像性
名家外の200集団の社会を使い倒す。脇キャラ配置の豊かさ。
物語骨格 ⑤
内省
「自分は何者か」を問う、でも答えに辿り着かない。
02 · WORLD

世界

1700年隕石落下から326年、七世代。魔法は血で継ぐ、計測可能・遺伝的な現象。

1700年、隕石が落下した。接触した生物の血にのみ魔法が宿るようになった。現在は隕石落下から 326年経過(現在 = 2026年相当)、発現する血筋で 約七世代。魔法は計測可能・定量的・遺伝的。接触血統の中でも確率発現(遺伝子くじ)し、発現しない者もいる。魔力の「量」は連続遺伝、「種類・技能」は個人依存。

世界そのものは立憲連邦のかたちで、王はもう象徴、議会と六つの極がゆるく釣り合いを取りながら回している。かつての名家は旧華族化 — 上院席・学院理事・社交界で影響は残るが、日常の実権は薄い。学院都市 RACINE は、その均衡の真ん中に置かれた、子供たちが魔法を学ぶ街だ。

04 · MAGIC SYSTEM

魔法6軸モデル

魔法とは、世界に満ちる力に干渉する行為。6軸で語れる。
軸名前意味・値の例
①方向ベクトル(対象・向き)。値で分類しない、対象記述のみ。
②量どれだけの力に干渉できるか。感受性(遺伝) × 訓練。
③質どれだけ巧く干渉できるか。精度・効率・副作用・可逆性・安定性。
④属性何に干渉するか。物質 / エネルギー / 情報 / 魂 / 命 / 非物質。
⑤時間いつ・どれだけ効くか。瞬間 / 持続 / 永続 / 過去介入 / 未来予測。
⑥変換結果なにがどう変わるか。なし / 形状 / 状態 / 領域跨ぎ / 因果 / 再帰。
A · 対話術
TAKANI 系
石と話す受動型。残響読みも含む。
B · 変成術
KROSS 系
鍛造・加工の能動型。物質変換。
C · 測量術
VEXALIA 系
計測・管理・規制。非魔法側の技術。
D · 封印術
KROSS 副系統
危険な力を閉じ込める。
E · 復元術
EMBERLYN 系(表)
失われたものを元に戻す。実体は A の変形。

Ambre の異常性: 属性 = 魂、変換 = 領域跨ぎ + 因果、時間 = 過去、質 = 異様に高い精度。発現初日から魂位相に触れる(TAKANI 長老クラスの領域)。彼女が「復元している」と思っているものは、この6軸で見ると復元とはまったく別の方向を指している。

05 · POLITICS

政治体制

立憲連邦・象徴君主・多極均衡。50年前の革命の余波が水面下で動く。

連邦国家: 西 VEXALIA 州 / 北 KROSS 州 / 南 TAKANI 自治区 / 中央エンバーリン圏(首都 + 学院都市 RACINE)。州自治はあるが中央が強い。

EMBERLYN 家族: 父 178cm = 家の復活に熱心 / 母 165cm = 距離を取って見ている / 兄 19歳 175cm = 発現せず焦り、S1 で手紙が途絶える / 姉 17歳 162cm = 詩と絵に逃避。曽祖母 102歳 138cm は超高齢で TAKANI 側にいる。Ambre だけを「Iya(イヤ)」と TAKANI 名で呼ぶ、二重名前構造の唯一の証人。

親世代の「子だくさん」応答: 7世代衰退への焦りから、家全体が量産で確率を上げる戦略を取ってきた。特に主人公の親世代(父・母・叔父叔母たち)は子だくさんで、Ambre のまわりには超親戚(多数のいとこ・叔父叔母)がいる。誰も大きな発現をしていない中で、末っ子の Ambre だけが「当たり」を引く。しかしその真の原因は、家の努力ではなく 四代前の曽祖母の一度の不義 — 家の記録から消された TAKANI 混血。二重の皮肉が本作の背骨を強化する。

大人キャラ(未詰め): 学院長 / 担任教師 / 後見人 / VEXALIA 系政治家(血統審査強化派) / TAKANI 長老 / 異端科学者(隕石再活性化を察知) / 地下新聞書き。叔父叔母・いとこ枠(数・性格未決)も追加。
